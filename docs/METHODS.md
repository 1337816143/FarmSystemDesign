# 方法、边界与验证计划

## 1. 定位与对象

研究原型名称 FarmSystemDesign，模型版本 `screening-0.1.0`。它不是FarmDESIGN、FarmSTEPS或其他现成模型的官方版本。空间数据与生产经营边界独立表达：村组与主体通过ID关联；地块通过farmId关联经营主体。

只有真实地理与历史气候背景。3村组、12主体、36地块和全部生产系数由固定种子生成，研究范围为演示窗口。以后用户可导入自己的资料，但“用户声明实测”仍标为未核验。

## 2. 时间、单位与活动

选定2025年一个季度的3个月，按一段虚拟核算窗口计算。基础系数为每ha每窗口。它不是已验证的当地物候或生育期。换季度不传递土壤、作物、牲畜、储水或资金状态。面积以ha计算（1ha=15亩），需求m³与工日，氮kg N，可食能量GJ（代理）。

年生活动为水稻、露地蔬菜、豆科与覆盖/休养。固定果园、水产塘不可在优化中替换。家禽规模为固定输入，并不是当前决策变量。土地每块选一种活动，不能一块重复配置两个主作物。未实现轮作、混作、分块连续面积决策和投资优化。

## 3. 核算关系

活动收入=面积×参考收入×土壤产出因子×冲击因子×价格倍率；价格倍率只影响蔬菜。冲击因子=max(0.35,1−冲击设置×活动风险系数×2)。无随机天气概率，风险系数未经估计。

月补水需求=面积×max(0,参考需水×月比例−公开月降水×降雨情景倍率×10×有效系数)。种植有效系数0.35、水产0.15。它是透明的需求核算，不是灌溉物理模型。公共气候缺失时按0mm保守核算，同时明确警告缺失，不展示伪造实测曲线。

劳动按活动参考工日分配到3个月。每个月均检查对应决策单元水和劳动需求不超过配额。满足月度总量不意味着逐日排程可行。

收益=收入−基础成本−矿质氮×8元/kg N−水×0.35元/m³−劳动×100元/工日−跨户粪肥转移×2元/kg N。基础成本定义为不含上述单列费用；未包含地租、折旧、完整库存与融资。基准若不可行，其名义产出不得当作实际可实现产出。

家禽输入：每只窗口收入28元、基础成本16元、饲料N0.4kg、产品N0.12kg、粪肥N0.22kg、可食能量0.008GJ、水0.07m³、劳动0.04工日。回收率0.65，当窗口有效率0.45。全部为虚拟值。

粪肥先满足自身活动需求，再允许按模式共享剩余量；接收端付假设转移成本。矿质N=max(0,活动N需求−使用的回收粪肥N×0.45)。回收粪肥使用量不得超过本组实际回收量。未使用部分仍在系统氮余量内，不凭空删除。

系统外部N输入=矿质肥N+饲料N+生物固氮；产品输出N=作物/禽产品/水产品N。系统N余量=输入−输出。内部粪肥转移不再次成为系统外部N输入。缺少大气沉降、土壤库存过程、畜禽增长、储存变化及过程分损；余量绝不是直接氮污染或温室气体排放。负余量可能表示库存消耗或参数不一致。

## 4. 多主体边界

- independent：每户的水、劳动、粪肥独立，不借用其他户配额。
- cooperative：只在所选同村成员内共享；其他村及未选成员均不参加。
- centralized：合并所有选中主体的资源，仅为集中协调假设。

这没有证明合作被同意。也没有建立实际水权、共享物理设施容量、运输路线或利益分配规则。当前水/劳动预算由户持有，共享时仅合并这些配额，不从外部凭空增加资源。

参与收益约束=新收益≥基准收益−(1−比例)×|基准收益|，逐成员检查。对负基准不能简单乘比例。参考基准若本身资源不满足，应谨慎解释该名义底线。

## 5. 搜索与多目标

可变地块≤5：完整枚举四类离散活动的组合。更大问题：基准、同一活动方案、单地块邻域、固定种子随机候选与可行起点局部改善。默认1600随机候选，检验数随去重和局部搜索变化。

候选支配关系：收益不低、用水不高、劳动不高、氮余量绝对值不高、能量不低且至少一项严格改善。输出相对“已检验候选”的非支配前沿，并非真实连续问题全球前沿。最多展示36个经偏好排序的候选，其他候选数仍报告。

综合偏好=归一化收益0.45+节水0.20+降低绝对氮余量0.15+能量0.20。归一化范围来自本次可行候选。劳动在可行性及支配筛选中使用，但不再额外加权。可单独选择收益、水、氮、能量排序；不把某一种权重当成客观真理。

收入±20%、成本不变的敏感性区间不是统计置信区间、概率预测或完整不确定性传播。当前未实现经校准的反脆弱/杠铃策略实验。

## 6. 快照与反馈

每个方案保存原输入数据、气候、范围、配置、结果、版本与时间。输入指纹为可复现检查用的FNV散列，不是安全或防篡改签名。更改当前条件后旧结果显示“已过期”，不能直接保存为当前条件方案。

“拟采用”只表示意向。反馈需要同对象、同时间和同单位，选择虚拟练习或用户未核验数据，并记录来源。不会自动用反馈校准模型，不会把记录等同现实执行证明。用快照着色当前地图前应检查几何是否已改变。

## 7. 科学验证的下一步

替换示例主体与参数；确认PhD1作物数据的时间/单位/接口；核查空间经营边界；独立检验基准和关键响应关系；检查方案可实施性、参数敏感性和公平分配。比较空间显式与平均、固定与更新、独立与协作时，需要相同统计口径与足够数据，不能从界面功能直接推导研究结论。

28项以上单元检查只覆盖软件和代数一致性；浏览器测试覆盖交互，并不构成科学有效性验证。
