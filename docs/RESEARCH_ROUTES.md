# 双路线研究设计与数据验收边界

状态：2026-09-30 工作设想。海南全域尺度仍在讨论，尚未确认为正式课题变更。本页用于讨论，不是已批准的研究计划或论文结论。

## 共同的研究主线

两条路线都围绕空间差异、时间变化、农业生产组合、资源约束、多功能表现与适应性调整。改变尺度时必须重新定义决策者、可改变的变量、资源边界和验证对象；不能把同一套农场优化代码直接套到全省。

| | 路线一：proposal 案例农场 | 路线二：海南全域备选 |
|---|---|---|
| 决策单元 | 农户／农场及其地块；村庄与景观是背景和可能的协作范围 | 市县或有论证依据的农业生态分区；不存在默认的全省统一经营者 |
| 可回答的问题 | 活动怎样组合，水、养分和劳动怎样分配，变化后哪些决定仍可调整 | 生产结构和风险在哪些地方、年份不同，哪些区域调整方向值得比较 |
| 关键产出 | 真实基准、农场模型、方案权衡与后续验证 | 同口径区域诊断、条件明确的情景比较与适用范围 |
| 核心缺口 | 经营权、实际活动、逐期资源、成本和独立验证 | 市县时序与代码、区域约束、响应参数和独立验证 |

## 路线一：从演示窗口走向真实农场系统

1. 选定案例区、经营主体和活动范围；把地块、管理记录与资源流按同一时段对应。现有 FTW 图斑只是公开预测空间单元，不能代表真实田界、经营权或代表性样本。
2. 重建现实基准，逐项核对水、养分、劳动、投入、产出和成本。与 PhD1 协定种植方案接口：活动定义、产量及资源响应、单位、时间尺度、适用条件和不确定性。
3. 检验基准和关键响应关系，再比较独立、受条件约束的协作、固定与可更新策略。只让决策者调整现实中能改变的事项；已经投入的设施和已种多年生作物需要调整成本和时点。
4. 分开报告食物供给、资源效率、收益、社会可接受性和环境代理指标。模型得分提升不等于现场改善。

## 路线二：从全省诊断到有边界的区域情景

1. **先定单元和统计口径。**建立市县／分区代码、边界年份和单位表，抽取多年同口径的作物面积、产量、畜牧和水产等指标。辨别行政区变化、总量与人均量、播种面积与土地面积、现价与可比价。
2. **诊断差异与变化。**匹配气候、土壤、土地覆盖等资料，保留各源的年份与空间分辨率。检验缺失与不确定性，避免将 10 m 分类图说成逐地块经营记录。
3. **建立可检验的情景。**每个情景明确谁有权改变哪些活动、可用土地与水资源、市场与政策限制、影响的时段，以及不能改动的存量。区域模型的响应系数与约束必须有来源并做敏感性分析。
4. **独立验证。**使用不参与参数拟合的年份、区域或调查材料检验关键输出。典型农场可帮助检查过程与可实施性，但不能用少数案例推断全海南每户的结果。

当前仓库**仅实现省级年度背景展示与数据审计**。市县诊断、区域情景和全域优化尚未实现；界面不应显示这些工作的数值结论。

## 跨尺度连接

只有当区域单元与农场样本的抽样、权重及生产活动定义有明确关系时，才可尝试用典型经营系统检验区域参数。农场模型提供过程解释与可实施性信息；区域统计提供覆盖和变化背景。两者要分别保留数据版本和验证结果，不能相互冒充。

## 数据登记与接入门槛

每份资料至少记录：提供者、原始链接、许可、获取日期、观测年份、空间单元、时间粒度、变量单位、缺失值、处理脚本与校验值，以及“观测／统计／估计／假设”身份。接入前核对表头和分母；接入后做单位、行政代码、跨年可比性和独立样本检查。数据来源已经确认，只表示可以继续取数，**不表示已进入模型**。

本版逐项清单在平台“研究路线”页，可导出 CSV。当前唯一展示的全省数值来自[海南省统计局 2025 年农业经济解读](https://stats.hainan.gov.cn/tjj/ywdt/xwfb/202601/t20260123_4016316.html)，均为海南全省年度总量，不是市县值。其他候选来源：[海南省统计局 2025 年统计年鉴入口](https://stats.hainan.gov.cn/tjj/tjsu/ndsj/2025/18gb_list.html)、[ERA5-Land](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land)、[ESA WorldCover](https://esa-worldcover.org/en)、[ISRIC SoilGrids](https://docs.isric.org/globaldata/soilgrids/)。候选产品还没有下载为本平台的全域分析数据。

## 需要导师组决定的事项

1. PhD2 的主要决策单元，以及农场和区域两层是否都列为正式研究对象。
2. 原 proposal 中农场模型、数字孪生、PhD1 协作和现场验证如何保留。
3. 全域路线的论文目标止于诊断、情景评估，还是有足够数据支持的优化。

在这些决定前，平台维持双路线与明确状态，不把海南全域备选方案写成已批准变更。
