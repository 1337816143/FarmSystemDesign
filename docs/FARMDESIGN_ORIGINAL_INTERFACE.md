# FarmDESIGN 原版界面与本地还原说明

本地版本：0.3.26。核对对象为已有的作者程序 **FarmDESIGN 4.21.5.0**。

## 两种入口

进入网页 FarmDESIGN → 原版界面：

- **在浏览器中打开原版**：网页呈现并操作原作者的真实 Windows 窗体。
- **打开原版软件窗口**：在本机桌面打开同一套真实窗体。
- 同一会话在两个入口之间切换，使用同一份独立数据库。首次打开时复制当前网页输入；此后原版会话和网页项目分别保存。
- **取回原版项目输入**：取回后重新核算。覆盖前的网页项目自动备份到会话的 `WebBeforePull/`。
- **继续以前的原版会话**：恢复保存的数据库。关闭网页不等于删除会话。
- **原版输出文件、数据库与使用手册**：下载真实输出、MDB 数据库和原手册。
- **导出完整原版会话**：包含数据库、原版输出、项目快照、照片文件和取回前备份。程序本体随便携包提供。

会话保存在 `UserData/OriginalInterface/`。程序文件夹移动后，恢复会话时重新指向该副本的输入、输出目录。一个会话同一时间由一个本地服务连接。

## 输入与输出目录

原版“Input folder / Output folder”可选择其他本机目录。浏览器显示文件夹选择窗口时，还可以在窗口上方填写完整路径，点击“定位此文件夹”，再点击原版窗口中的“确定”。输入目录须包含原版的 `FarmDB.mdb` 和 `de.mdb`。

取回输入、文件列表、文件下载及完整会话导出均使用原程序当时实际选中的目录。目录和网络计算设置从正在运行的原程序读取。快速编辑后的取回会等待原版数据库连接与独立读取连接的数据一致，再返回结果；未完成保存时明确提示，不返回旧记录。

保存、关闭或导出会话时，所选外部输入、输出会在 `DirectoryCopies/` 保留按内容区分的副本；相同内容复用，历史副本保留。`directories.json` 记录原路径及便携副本。原位置重新打开时沿用仍存在的所选目录；整个会话移动后使用自身携带的副本，即使旧路径仍存在也不会写回旧项目。原路径缺失时使用已保存副本；没有保存副本则提示恢复原目录，不替换成另一个项目。

直接关闭原版窗口也会在网页停止刷新时保留目录副本。复制整个便携版前仍应保存并关闭原版会话，或运行“停止Farm.cmd”。文件夹选择窗口保持打开时，请先完成或取消选择。

本地服务或电脑重启后，网页会将已经退出的原版窗口识别为“已保存并关闭”。点击任一原版入口继续原会话，无需新建项目。

## 复用与验收

作者原始 `FarmDESIGN.exe`、`DAL.dll`、`DE.dll`、`ParetoDE.dll`、`NetworkMetrics.dll` 保持原文件；自建 x86 宿主负责独立会话、显示、操作及输入输出转换。没有另写 FarmDESIGN 公式，也没有用图片代替可操作窗体。

浏览器模式使用专属 Windows 桌面，只呈现本进程的窗体，不截取宿主桌面或注入全局鼠标键盘。按钮、输入验证、设置和优化仍由原程序处理。

| 内容 | 验收 |
| --- | --- |
| 作者案例 79、80 | 真实 GUI 模型与网页调用的原版引擎逐项比对：20 组输出，5,469 + 4,881 个末级值，无差异 |
| 输入编辑 | 文字、费用实际写回 MDB；费用增加 1,000 后原版可支配预算减少 1,000 |
| 取回与恢复 | 取回前备份；原版输入进入网页；关闭后编辑仍保留 |
| Explain | 19 个原版页面逐页呈现原始输出控件 |
| Evaluate | 原版决策变量、目标和约束检查 |
| Explore | 保留先关闭网络指标计算的原版前置规则，实际运行原优化器 |
| 设置 | 模块、饲料、能源、营养、温室气体、NFD、网络的真实窗口 |
| 资料库、文本导入、备注 | 原版窗口及页签；备注写入 NTE；资料库子表与备注关系保留 |
| 文件 | 手册和完整会话下载的哈希一致 |
| 全局语言 | 中文、英文、双语改变呈现，切换前后核心输入表相同 |

复核脚本：`tests/farmdesign_native.py`、`tests/farmdesign_original_browser.py`、`tests/farmdesign_original_workflows.py`。短迭代预算、编辑标记和测试备注只用于软件验收。

## 更清楚的输入

- 模块编码的正负号表示启用、停用，数组顺序表示页面顺序；改为勾选及上下移动。
- 食物组按 `DRF.DrfID` 对应，保留第 0 项占位。实际窗体单位为**克鲜重/消费单位/天**，不再显示整串 `0@0@…`。
- 分时数据逐时段编辑，未编辑部分保留精度；不能一概认为需要加总 100。
- 经定义核实的 0–1 比例用百分比显示，写回时还原；原本已是百分数的含量不重复乘 100。
- 补充 SV、NE、ME、TDN、DVE、CP、VEM 等代码说明，保留作者原始定义。
- 优化目标、约束、精确值、参数及图轴引用保留原编号，不用网页默认目标或较小预算替代。

全局语言只改变显示，不改数据库字段、用户命名、输入值、模型绑定和程序集。专有名称、代码、共用符号可以保持原文。原版布局紧凑，双语较长时可改窗口大小、比例，或在现代输入界面查看完整说明。

## 准确的范围

1. 核对的是 4.21.5.0，不宣称其他版本也已复刻。
2. 作者案例有照片引用，但现有作者包及相关本地目录缺少 `CIMG0010.jpg` 等原照片。引用保留，不生成替代照片；可以补入用户自己的照片。
3. 原程序需要 Windows 和本机服务。静态 HTML 或 GitHub Pages 单独不能执行原程序。
4. 外部文件阅读器、Excel、资源管理器属于 Windows 外部程序。桌面入口按原程序调用；浏览器入口提供文件下载。普通计算及导出不要求安装 Office。
5. 外部输入、输出目录的选择、编辑后取回、下载、完整导出、重开和同机移动均已核对；尚未在第二台实体电脑复验。外部目录的文件随保存副本带走，外部程序或共享盘的并发改写不属于独立会话的一致性保证。
6. 逐项软件验收不是所有输入组合的数学证明，也不是海南实测、模型校准或研究验证。不能据此无条件宣称“百分之百验证”。

Jet 多连接缓存曾导致取回旧记录；会话现通过 ADO/JRO 刷新后读取。组件说明：[Microsoft Jet OLE DB](https://learn.microsoft.com/en-us/office/client-developer/access/desktop-database-reference/microsoft-ole-db-provider-for-microsoft-jet)。
