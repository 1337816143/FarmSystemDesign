# 海南全域路线的方法证据与设计边界

状态：2026-09-30 方法核对笔记。以下区分**来源支持的做法**与**拟用于海南的设计选择**；引用资料不等于海南模型已经建立或验证。

| 主题 | 来源支持的做法 | 海南路线的待验证选择 |
|---|---|---|
| 区域分型与参考农场 | [FAO World Agriculture Watch 方法框架](https://www.fao.org/world-agriculture-watch/tools-and-methodologies/waw-methodological-framework/en/)提供国家／区域农场分型、与利益相关者讨论分型、选取参考农场并持续监测的方法。原始研究也展示了利用普查资料识别农场类型、选择代表性农场，再考察农场结果上推的步骤（[Alvarez 等，2011](https://doi.org/10.1016/j.agee.2010.07.011)）。 | 先以市县逐年资料描述生产结构与环境约束，再根据**真实经营主体资料**建立农场类型；区域类型和农场类型分别建，不把一个市县当作一个农场。类型数量、代表农场数量和分型指标须经资料审计确定。 |
| 从样本推及区域 | [FAO 农业调查实例](https://www.fao.org/fileadmin/templates/ess/ess_test_folder/World_Census_Agriculture/Country_info_2010/Reports/Methodology_4/RWA_ENG_MET_2008.pdf)说明用抽取概率的倒数构造扩展权重；[欧盟 FADN 方法说明](https://agriculture.ec.europa.eu/system/files/2021-11/eu-farm-econ-overview-2018_en_0.pdf)按地区、经营类型和经济规模分层，对样本农场加权后汇总，并限定其代表的总体。 | 典型农场若仅按研究便利或专家推荐选出，只能检验机制、经营约束与可实施性。要报告市县／全省平均影响，须有总体框、抽样或可论证的校准权重、覆盖范围和不确定性；不能用若干案例简单平均代替海南总体。 |
| 农场与区域的模型边界 | [FarmDESIGN 原始论文](https://research.wur.nl/en/publications/multi-objective-optimization-and-design-of-farming-systems/)在一个实际农场上比较收益、有机质、劳动和氮损失的权衡，并进行了设计、输出和终端用户验证。[Landscape IMAGES 原始研究](https://research.wur.nl/en/publications/designing-a-hedgerow-network-in-a-multifunctional-agricultural-la/)以多目标、多尺度空间方案支持多利益相关者的景观讨论。 | 区域层比较政府／服务组织可影响的措施包、资源额度和投资安排；农户／农场层检验地块、劳动力、资金及参与条件。模型共享活动定义和单位，不共享未经检验的农场系数，也不假定省域有一个能直接安排全部地块的经营者。 |
| 适应与验证 | [IPCC AR6 WGII 第 17 章](https://www.ipcc.ch/report/ar6/wg2/chapter/chapter-17/)指出，多情景压力测试可比较稳健方案；适应路径需把近期行动、后续阈值、监测和调整连接起来，并留意长期投资锁定。FarmDESIGN 的原始研究将模型设计、输出和用户检验分开。 | 对同一目标与约束分别比较现状、固定措施、跨情景表现较稳健的固定措施、按可观测触发条件逐期调整的措施。触发条件、决策时点和已投入设施／多年生作物的调整成本应事先写明；用未参与校准的年份、区域或经营主体检验预测，并另做经营者可行性核查。具体阈值与验证划分待取得数据后确定。 |
| 海南可用的公开起点 | [《海南统计年鉴 2024》](https://stats.hainan.gov.cn/tjj/tjsu/ndsj/2024/202412/P020250116308974141111.pdf)目录列有 12-1 各市县耕地面积、12-8 农林牧渔产值构成、12-11 播种面积、12-13 主要农作物面积和产量、12-15 园林水果与茶叶、12-17 热带作物、12-19 牲畜与家禽等表。[2025 年统计年鉴入口](https://stats.hainan.gov.cn/tjj/tjsu/ndsj/2025/18gb_list.html)已经公开。海南省统计局说明历次普查后可能修订数据，使用时应以最新年鉴核对（[年鉴使用说明](https://stats.hainan.gov.cn/tjj/tjzs/tjbk/202306/t20230628_3443476.html)）。这里仅核对到目录，未逐表抽取或核验数值。 | 第一步建立“市县 × 年份 × 指标”资料审计表，逐表记录定义、单位、边界和修订。年鉴有市县农业表，并不证明水权、农场投入、劳动、经营权或可实施成本可得；没有这些资料时，相关指标只作明确假设或暂不计算。 |

**建议的最低科学关口：**先完成市县时序和分型的可重复构建；再取得有选样说明的经营系统资料，并校验区域与农场两层的活动定义；最后开展有限措施包的情景比较。只有响应参数、样本代表性、约束和独立检验足够时，才上推总体结果或声称区域优化。此顺序是本项目的设计判断，非上述文献已经证明的海南实证结论。
