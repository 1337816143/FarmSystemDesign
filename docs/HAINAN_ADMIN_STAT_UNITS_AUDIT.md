# 海南市县统计单元与边界连接审计（2026-10-01）

结论：**目前不能把网站中的 2017 年 geoBoundaries 多边形与海南年鉴市县农业数值做一对一填色图。** 名称、单元和空间范围均有实证不一致。可先用官方年鉴做注明年份的省级或市县列表／条形图；县域填色须等现势、可复用几何及逐项匹配检查通过。

## 现有几何与 18 个农业统计行不能连接的直接证据

[geoBoundaries CHN ADM2 元数据](https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM2/)把该版本标为 `boundaryYearRepresented: 2017`，发布单元共 2,391 个。仓库从其简化 GeoJSON 裁出的 `data/hainan/county-reference-2017.geojson` 确有 18 个面，但实际 `shapeName` 包含 `Qiongshanshi`（琼山市），**没有** `Wuzhishan`／五指山市；还有 `Shanyashi`、`Chanzhoushi` 等拼写及旧称问题。官方年鉴表 12-1 则有五指山市、没有琼山市。故“18 面 = 18 行”的计数相等只是巧合，逐项键连接会漏配或错配。海口／三亚等地级市和县级 ADM2 的层级也须分别核查，不能只做字符串相似匹配。

该图层的原始许可证在 API 中为 PDDL v1.0；[geoBoundaries 的网页使用说明](https://www.geoboundaries.org/)还要求显著署名和链接。它可以保留为**非官方历史位置示意**，并继续默认关闭；不应在其上画“现势市县耕地面积”的分级设色。

## 现势代码与几何的获取门槛

- [民政部《行政区划代码管理办法》](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202512/t20251204_528920.html)规定省、地、县级行政区划代码由国务院民政部门确定，并由国家地名信息库按年发布；这条发布规则**只涉及代码**，不等于提供可再发布的边界几何或统计单元面。
- [国家统计局 2025-08-25 答复](https://www.stats.gov.cn/hd/lyzx/zxgk/202509/t20250903_1960996.html)称具体的“统计用区划代码和城乡划分代码”自 2024-10 起不再公开。它与民政部门的行政区划代码不是同一套公开产品；规划系统不应把过时的统计用代码抓取库称为现势权威表。
- 现有官方年鉴 PDF 的版权页（PDF 第 4 页）写明“未经许可，本书的任何部分不得……翻印、拷贝、仿制或转载”。官网可下载不等于许可整表镜像或再分发。平台可链接并引用表号、少量必要事实；批量重发布表前应取得出版方允许的使用范围。
- 本次没有核实到同时满足**现势年份、完整 18 个海南岛市县、可公开复用几何、明确许可**四项条件的边界文件；不能将第三方旧图层改名为“现势行政边界”。

## 可执行的连接验收

1. 建立 `stat_year`, `source_table`, `stat_unit_name`, `admin_code_system`, `admin_code_year`, `geometry_source`, `geometry_year`, `geometry_id`, `join_status` 字段；三沙、洋浦和海口／三亚下辖区的合并规则单列。
2. 取得获准使用的现势几何后，先核对 18 个农业统计单元的**双向完整匹配**；特别检查五指山、原琼山市范围、海口／三亚／儋州以及离岛。严禁以“看起来差不多”的拼音自动补配。
3. 验证几何无重叠、无异常缝隙，使用合适投影核对面积量级和行政层级；保留原始文件哈希与人工审签的 crosswalk。通过后才允许以市县填色展示年鉴指标。
4. 数据图表注明“耕地面积／播种面积／土地覆被类别”的不同定义；市县年鉴面积不可拿来验证 WorldCover 像元分类准确率。最新 2025 册逐表复核后，再决定是否替换 2023 年指标。
