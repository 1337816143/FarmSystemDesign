# 原AGD目标与方案B的对齐依据

## 研究依据与引用范围

依据原 AGD 课题6 proposal：第4页 PhD2 三目标、第5页 PhD1–PhD2 协作（第3页为 PhD1 任务背景），仅保留与研究设计直接相关的目标、共同案例接口和范围说明。第4页已明确海南研究焦点；本说明不把“海南”本身当作新增创新。

## 第4页PhD2三个目标原句

1. Mapping spatial heterogeneity and temporal variability in selected farming systems. Developing a methodological framework for adaptive management of multifunctional systems.
2. Developing and testing a modelling tool to design adaptive, multifunctional farming systems by integrating cropping systems and other production activities.
3. Optimizing resource allocation (nutrient, water, labour) use in the farming systems to foster adaptive improvement of system performance.

本报告将它们简称为“时空差异与适应框架”“跨活动模型开发与检验”“养分水劳动配置与适应改进”；这三个简称是中文概括，不替代以上原句。

第4页在目标前要求模型显式考虑时空差异、相应不确定性与风险，活动包括PhD1作物系统、畜牧、水产，也可能包括热带农林。五个评价领域为food security、resource use efficiency、economic profitability、social acceptability、environmental impact。这里列活动范围并不意味着在数据缺失时可以补造某个模块。

## 第3–5页两个博士的协作接口

原计划要求 PhD1 与 PhD2 在共同案例区协作：PhD1 开发和检验适应性作物系统，PhD2 负责空间配置、与其他生产活动的整合，以及资源和生物物理/社会经济约束的反馈。双方共同形成状态与反馈记录；这不是现有平台已完成数字孪生或现场验证的声明。

B 因此保留共享案例与数据接口，不把 PhD2 全部改成脱离 PhD1 的省级统计优化。PhD1 的作物适宜性、C-AMS 与逐季适应试验仍是候选及适用条件来源，PhD2 不另立重复的独立作物试验任务。

## 对B的直接含义

原稿研究单位是selected farming systems及共同案例村庄/景观；B提出“海南分层覆盖与跨主体共享资源配置”，是新的范围与推断设计，需要讨论确认。原稿既有海南焦点，所以B的可检验增量应是：聚合究竟遗漏哪些可实施性约束、跨活动反馈怎样改变可行菜单、在同等信息和资源条件下何时允许调整有价值。不能把放大地图、增加县数、换优化器或调用数字孪生一词当作创新已成立。
