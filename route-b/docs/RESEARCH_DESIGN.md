# 海南大尺度路线 B：依据、目标迁移与可计算系统

2026-10-06 研究讨论稿。原 proposal 三目标作为路线 A 保留；B 是重定义研究覆盖、决策和推断尺度的备选。原 proposal pp3–5 已明确海南焦点，不把“海南”本身当创新。B 未获正式科学批准，也未校准或科学验证。

## 1. 先由原文确定问题，不先确定算法

原 proposal 的 PhD2：①空间异质、时间变异与适应性管理框架；②整合作物系统和其他活动，开发和检验模型；③养分、水、劳动配置的适应性改善。五领域为食物安全、资源效率、盈利、社会接受、环境影响。PhD1 提供适宜性、C-AMS、季节适应作物试验；PhD2 负责空间部署、跨活动资源与反馈，共享案例节点不能因扩尺度而删除。

- Liang2022：同类观察系统的非支配/优秀实践可形成现实候选，不构成因果或迁移成功的证据
- Liang2023 pp534–537：作物×季节、历史与返回期约束后生成轮作；固定产量，不声称生长动态
- FarmSTEPS2026 pp4–7、17：土地单元关联候选、历史及逐期整场约束；其确定性枚举是限定案例，不可省域逐地块照搬
- Xu调查及博士第4章 PDF179–187、206、217–223：分层和类型内比较；SC3面积重配与SC4改系数+重配分开；原模型年度劳动且无硬劳动上限，海南迁移要检验季节容量的增量价值
- Dong2026 期刊pp3–6、Eqs1–15、补充S23–S60：全岛N/P物质流与生产/环境边界；空间平均和系统边界不能直接下推为经营者配额或法规
- Qu2025 §2.2、§3.2：物料从产生到处理、可利用和接收需守恒，保N不保证全系统损失或成本下降
- Cheng2023/2025：感知、观点、参与者底线与采用条件是不同对象，Q因子不是优化权重；研究者设置约束不等于已测接受度
- Groot2007/2018：个体可行不保证高层可行；位置依赖资源连接和单纯面积加性指标须分别建模
- Groot2012、Ditzler2019、Groot2017：活动、产品和物料分开；家庭劳动、家庭结余与农场毛利边界不同
- Novotny2024：地图配置和真实测量分开；Breure2024：评价对象、指标及验证覆盖不能混淆；Mixed2026：土地、金融、知识和合作影响采用
- Toorop2023/ Verdouw2021：不能从概念或网页推论反脆弱/数字孪生；须有状态、观测、决策、执行和结果记录

## 3. 数据、尺度与证据关口

省/县统计提供时间序列和覆盖框架；环境层提供可用分层先验。经营单元决定权限，真实地块和活动季记录状态；县界、流域、灌区和物料网络不必整齐嵌套。水必须有水源和可达量，劳动按实际关键时间窗；物理土地与复种面积分开。

最小关联键：环境层、经营ID、生产单元ID、实际日期/季、活动/序列、管理和参数版本。每个字段需要量纲、来源、观测/迁移/合成身份、空间/时间支持及误差。

198条植物候选表没有农场/地块ID、地理位置或统一年份；23/33字段全空。不能当198户样本、映射海南、直接校准生产和资源。Scores不能当物质量；365/生育期不是真实茬数或轮作返回期。

本页模型严格只接受 synthetic 身份和 absent 代表性，拒绝偷偷改成已观测/已代表/已接受。不支持给合成单元贴真实坐标。现有海南公开地图保留为背景，周边地图不扩大研究区。

## 4. 第一条已实现、可计算的链

本原型有两个任意合成层、每层3个完整经营菜单、两个资源时期。候选不生成真实作物轮作，不把两层称为海南实际类型。

1. 读取并严格验证 JSON 单位、来源、菜单、数量、时期与水源绑定
2. 每个菜单检验土地类别、经营面积、逐期本单元劳动及可达水量
3. 对每层“若干个完整菜单分别采用几份”枚举非负整数构成，份数之和等于该层假设经营单元数；不会拆分/无限线性缩放家庭资源
4. 汇总产品、毛利、外部N/P及资源量；共用同水源的单元受每期源容量约束
5. 单独检验粮食/蔬菜底线和N/P外部输入情景上限，不能用更多蔬菜抵消粮食缺口
6. 对可行完整结果用毛利↑、外部N↓、总用水↓作非支配筛选。P保留硬情景上限，五评价领域保留在结果与研究协议中；该三目标选择并非参与式定稿
7. 输出全部有限组合、每条违例及超额、完整前沿和版本记录；可保存/导出、导入重算和重置

默认9种组合中，年度平均允许8种，逐期约束仅允许5种，3种被年度诊断遗漏约束。两个关键独立反例：
- 合成菜单劳动[120,20]h，小于全年供给[80,80]h的总量，但第一期超40h
- α均衡65m³ + β用水集中80m³，各自在100m³个体水量内，却共同超出130m³共享源15m³；将β连接到另一个明确有容量的合成源后，此组合通过，产出组成和加性指标不变

因此位置在这个原型中体现为资源连接关系；不是画不同颜色当作空间机制。没有距离、水文迁移或真实GIS响应。

小例选择完整枚举，只为核查账本和约束。上限2000种完整组合，超过直接拒绝，不抽样后冒称完整前沿，更不将此解释成省域优化器。

## 5. 跨活动接口与未实现内容

独立N/P面板复用审查工作包的纯物料分份函数：同一来源 N40/P20，接收可利用N容量40、总P容量10、N可利用比例1，则最多接收半份，即N20/P10；其余仍在源端。1000个确定性合成例检查元素守恒、成分一致和双容量。

该面板与主菜单没有数值耦合，这是显式防止“菜单已有固定肥料/产量收益，又额外加循环收益”的重复记账。它只是回收物料接口，不是动物/水产生产模型、完整农场P平衡或可执行物流。要耦合必须取得成分/活动数据、可利用量、需求、时窗、运输储存、费用与权限，并重新评价菜单。

未实现：真实环境/作物过程响应、实际作物历史与返回期生成、PhD1试验导入、完整跨活动链、现金/雇工/市场/政策约束、实测接受度、省域权重、损失通路和适应更新。当前所有“通过”只指显式实现的合成约束。

## 6. 适应性和验证计划

记录初始信息、已承诺活动、可调整动作及转换费；每次只用到当时可观测的信息。相同候选/预算/外部轨迹对比固定与可调策略，分别改变空间信息、时间信息、活动库和系数，避免把额外资源的价值冒称适应价值。无概率证据时用命名冲击情景，不给伪精确风险分位数。

数据检验包括身份、单位、面积闭合、时间冲突和地图类别精度。模型验证需独立农场/地区/年份，宏观总量只能校验汇总。搜索验证有手算、完整枚举与独立实现对照，但不替代实证。采用/实施需参与者反馈和前瞻观测。

当前检验状态见 evidence/test-results.log 和 deliverables/acceptance.json。控制器的DOM存根测试不是浏览器视觉验收；本执行环境浏览器受限，真实浏览器桌面/手机、下载与原站集成待允许的验收环境检验。
