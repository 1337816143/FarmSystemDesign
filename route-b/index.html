数据 / 尺度 / 模型

省县资料用于覆盖框架；环境与经营资源层识别不可互换性；经营单元、地块与活动季决定权限和资源。逐期水源与劳动能力不能由全年总量均分制造。

先用有单位、来源和适用环境的活动系数建账，再为结论敏感且可校准的机制增加过程模型。先经营内菜单，再地域组合；不以全岛地块暴力枚举作为设计。

198条植物表无农户 / 地块 ID、位置、统一观测年，23/33字段全空。只能帮助整理候选与缺项，不得映射到海南或转成模型系数。Scores 的评分不能当 kg、m³、h 或货币。

合作 / 验证 / 升级关口

PhD1 提供环境适用性、作物序列、日历、投入产出与误差；PhD2 回传哪类经营者、哪一期受水、劳动、N/P 或资金限制。保留共享案例节点，是否扩大案例及首个其他生产活动待确定。

数据身份与单位检查 → 手算 / 全枚举软件检验 → 独立农场 / 地区 / 年份模型检验 → 参与者接受与前瞻实施。前一层通过不能替代后一层。

无非作物资料：作物阶段可推进，但原目标2未闭合。无代表性权重：可做分层机制情景，不能报全省收益或改善比例。

五个绩效领域如何保留
食物安全

按产品分别报供给代理；不把蔬菜与粮食吨数相加当粮食安全

资源利用效率

先报 N/P、水与劳动绝对量；效率必须说明分子分母

盈利能力

仅合成已计变动成本后的毛利；不是家庭结余或完整利润

社会接受

尚未测量；需要真实最低要求、拒绝条件、方案反馈与采用证据

环境影响

输入减收获仅为简化收支差；不等于淋失、温室气体或水污染

本原型仅用毛利↑、外部N↓、取水量↓作可解释前沿，粮食产出与N/P输入上限是情景约束。没有任何“社会接受权重”，也未将这三目标组合当作导师或参与者选定的最终目标。

适应性：完整检验协议，尚未计算策略收益

C0 实际基线 → C1 年度平均固定 → C2 分层固定 → C3 逐期资源与跨活动守恒固定 → C4 允许按已知信息调整。比较应使用同一数据版本、候选库、预算和外部轨迹，分离新增候选 / 改系数 / 重配置 / 调整权的作用。

每次更新须记录可观测信息的时间戳、已播种和合同锁定状态、可调动作、转换费及延迟。不得提前读取未来实际天气或价格。当前小例只比较相同分层、相同菜单下的年度与逐期静态诊断差别，尚无真实初始状态、滚动更新或适应性收益计算。

02 / COMPUTABLE VERTICAL SLICE

经营菜单 → 共享资源 → 可行组合

改变假设后重新运行。年度模式只是诊断对照：会明确指出被平均掩盖的逐期违例。

合成输入

数量是相同资源条件下的假设经营单元个数，不是海南抽样权重；改变数量会重算资源和产出。仅本页内存保存，不读写路线 A 的浏览器空间。

检查所有菜单与个体约束
日期事件 → 逐期资源入口

纯合成日期示例；不是作物日历、实测、校准或适应策略回放

所有时期为连续半开区间 [start,end)，按本地日历日期处理；只接受 h 和 m3。必须明确完整覆盖，缺值不补零。

日期 JSON 尚未采用。关闭或取消只取消待处理操作，已采用关联仍保留。

日期原输入、规则、来源和重算审计随完整归档及恢复快照保存；导入时重新核对。修改已关联资源或时期须先显式移除关联。关闭或清除预览不会移除已采用的日期记录。

查看 / 编辑完整 JSON 输入合同

只接受有完整单位语义与来源声明的合成输入。缺失、空值、错时间长度、无水源绑定、伪造代表性状态会拒绝，不自动填零。

JSON 字段、原始标签和导出记录保持原样；语言只改变本页显示。

完整审计归档与输入恢复

会话保存完整运行，刷新不保留。快照用于恢复菜单运行原输入与模式；不保存独立N/P演示控件、当前选中组合或会话版本列表。完整结果归档包含全部枚举与审计细节，可能超过5 MiB导入保护，不能保证可恢复；请另存可恢复输入快照。快照保留完整输入、来源和假设标记、引擎及合同版本、有效配置与有界摘要，不含完整结果。导入快照仅校验内容一致性并独立重算，原完整审计结果不会载入。SHA-256不是可信签名。

03 / CROSS-ACTIVITY INTERFACE TEST

同一份物料，同时过 N 与 P 的门

独立接口例：固定成分的可回收粪肥如何分份。它不改变上方预先给定的菜单系数，避免重复计算循环收益。

全部为人工数值

容量是明确的情景输入，不是法规或海南实测；P容量不是P需求。未接入动物数量、饲料P、矿质P、运输、储存损失及田间响应，不能称完整跨活动或全农场P模型。依据 Groot2012 的物料接口、Qu2025 的处理链与 Dong2026 的N/P边界。
